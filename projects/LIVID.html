C&A T&R M,D&C

LIVID is a Human Digital Twin application designed to help users balance work, life, and exercise by providing personalised recommendations for physical activity. It uses data such as schedules, self-reported energy levels, and weather conditions to calculate a readiness score (how prepared the user is to exercise) and a benefit score (how beneficial exercising would be at that moment).

The system combines these scores to suggest optimal times for running or exercise, supporting better well-being and planning. The current prototype simulates this process using adjustable inputs and visualised outputs to demonstrate the concept. A future version would integrate AI and additional data sources, such as biometrics and sleep patterns, to continuously refine recommendations and act as a personal well-being coach.

What did I learn...

At the start of this course, I set four learning goals: analyzing and visualizing datasets, learning basic Python for data analysis, improving data visualization skills, and switching between System Thinking and Design Thinking.

I developed my data analysis skills through assignments and the group project, gaining confidence working with datasets and learning statistical analysis methods. I also used Python throughout the project, building a partially working prototype with support from peers and ChatGPT, which improved my foundational coding skills and taught me to work more iteratively. In data visualization, I learned it is an iterative and nuanced process, though I still need more practice. My fourth goal was fully achieved, as I became more comfortable shifting between System and Design Thinking and discovered a strong interest in System Thinking.

I also learned about synthetic data and its role in experimentation and gained deeper insight into Digital Twins. Overall, the course strengthened my technical and analytical skills and helped me grow more confident working with data-driven design processes.
